# Creative & Experiment Review Playbook — AdsCommand

**Version:** 1.0-local  
**Decision role:** review/checklist only; requires human approval before publication.

## Creative review

- [ ] Creative has stable identity/version.
- [ ] Hook/angle/product group is recorded.
- [ ] Copy respects approved claims and forbidden wording.
- [ ] Platform text/asset limits are validated.
- [ ] Fatigue comparison uses the same window and audience conditions.
- [ ] Performance source is complete and recent.

## Experiment review

- [ ] Hypothesis and primary metric are declared.
- [ ] Treatment/control or before/after window is declared.
- [ ] Minimum sample/data condition is met.
- [ ] Confounders and learning phase are recorded.
- [ ] Result is labelled positive/neutral/negative/inconclusive.
- [ ] No causal claim is made from simple correlation.

Creative output and experiment conclusions require human/BA review before launch or provider mutation.
